## 🔴 Tier 1 — 리텐션 & 핵심 학습루프 (서비스의 생사. 최우선)

### 1.1 단어 복습 루프 (SRS) ⬜ ⭐⭐⭐
- **지금**: 대화에서 단어 추출(`ENABLE_VOCAB_EXTRACTION`)만. 모아서 복습 안 함.
- **목표**: 추출 단어 → **내 단어장** 저장 → **간격반복(SRS) 복습** → "오늘 외운 단어 N개" 체감.
- **왜**: 이게 없으면 그냥 채팅앱. 있으면 "한국어가 는다"는 핵심 가치 + 매일 돌아올 이유.
- **구현**: 단어장 테이블(users.py 확장) · `/vocab` 저장·조회·복습 API · 플래시카드 UI · "복습할 시간!" 푸시.

### 1.2 학습 진척 시스템 (스트릭/레벨/배지) ⬜ ⭐⭐⭐
- **지금**: 호감도(Lv)는 캐릭터 친밀도지 "내 한국어 실력" 진척이 아님.
- **목표**: **연속 학습일(스트릭)** + **한국어 레벨 진척**(대화량·미션·단어 기반) + 배지/마일스톤.
- **왜**: 습관 형성(스트릭) + 성취감 = 리텐션 1순위 레버. (듀오링고 핵심)

### 1.3 재참여 푸시 고도화 🟡 ⭐⭐
- **지금**: FCM 푸시 있음(하루 4회 캐릭터 메시지).
- **목표**: 마지막 접속 기반 개인화·타이밍, **스트릭 위기 알림**("연속 3일 끊길라!"), 단어 복습 리마인드.

## 🟠 Tier 2 — 학습 가치 (돈 낼 이유)

### 2.1 발음 피드백 ✅ ⭐⭐ (2026-06-15 완료)
- **STT 입력**: 프론트 Web Speech API(voice-btn `toggleVoiceInput`) + 백엔드 Azure STT(`/transcribe`).
- **발음 평가 (신규)**: `POST /pronounce` = Azure Pronunciation Assessment. AI 메시지마다 **🎤 발음** 버튼 → 16kHz 녹음 → 정확도/유창성/완성도/종합 점수 + 단어별 채점 모달. (검증: 일치 92점 / 불일치 20점으로 변별)
- **남은 고도화(선택)**: 받침/음소(Phoneme) 단위 피드백, 발음 점수 누적·약점 단어 추천, 발음 점수도 XP/스트릭에 연동.

### 2.2 문법 교정 노출 강화 🟡
- `grammar_mode` 있음. 교정을 자연스럽게 + 나중에 복습 가능하게 surface.

### 2.3 레벨 적응형 난이도 🟡
- 온보딩에서 레벨 받음. 그걸로 응답 난이도·교정 강도·새 단어 빈도 동적 조절.

## ✅ 권장 실행 순서
1. **1.1 단어 복습 루프** — 채팅앱 → 학습앱 전환점 (가장 큰 지렛대)
2. **1.2 스트릭/진척** — 습관 + 성취
3. **3.1 Trial 종료 알림** — 전환 방어 (작은 노력, 큰 효과)
4. **1.3 푸시 고도화** → 2.1 말하기 → 4.x 글로벌 → 5 폴리시/모니터링

## 운영 노트
- 콘텐츠 톤: "비밀 사진/속삭임"(coffee 결제 보상)은 글로벌·앱스토어/결제사 정책상 **수위 점검** 필요.
- **QA/모니터링 자동화는 위 기능이 어느 정도 차오른 뒤** (안전망 단계). 알림 연결(Slack)·업타임은 거의 무료라 언제든 가능.
- 작업 방식: 각 항목 → 로컬(`localhost:8080`) 프리뷰 → 커밋·푸시 → 배포. 큰 방향은 `/office-hours`·`/plan-ceo-review`로 압박.
